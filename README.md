## 📖 关于本博客

这是一个持续更新近 10 年的技术博客，记录了从 2017 年至今的技术学习、项目实战和问题解决经验。博客内容涵盖后端开发、容器化部署、大数据处理、前端开发、系统运维等多个技术领域，包含 **300+ 篇原创技术文章**。

## 🎯 内容特色

- **问题导向**：聚焦实际开发中遇到的问题和解决方案
- **实战记录**：详细记录生产环境搭建、配置和故障排查经验
- **深入浅出**：提供具体操作步骤、代码示例和配置文件
- **持续更新**：保持技术内容的时效性和实用性

## 🚀 快速开始

本博客基于 Hexo 框架构建，使用 Obsidian 主题。

### 安装依赖
```bash
npm install
```

### 本地预览
```bash
hexo server
```

### 生成静态文件
```bash
hexo generate
```

### 部署
```bash
hexo deploy
```
